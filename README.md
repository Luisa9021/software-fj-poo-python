# Software FJ - Sistema Integral de Gestión de Clientes, Servicios y Reservas

Proyecto del curso **Programación (213023)** - UNAD. Fase 4: manejo de excepciones en aplicaciones orientadas a objetos.

## Descripción
Sistema en Python con Programación Orientada a Objetos, sin base de datos. Gestiona clientes, servicios y reservas mediante objetos y listas, y registra eventos y errores en un archivo de logs.

## Archivos
- `excepciones.py`: excepciones personalizadas.
- `logger.py`: registro de eventos y errores en `logs/software_fj.log`.
- `entidades.py`: clase abstracta `Entidad` y clase `Cliente`.
- `servicios.py`: clase abstracta `Servicio` y servicios `ReservaSala`, `AlquilerEquipo` y `AsesoriaEspecializada`.
- `reserva.py`: clase `Reserva` con estados y manejo de excepciones.
- `main.py`: simulación de 14 operaciones válidas e inválidas.

## Cómo ejecutarlo
1. Instalar Python 3.
2. Abrir una terminal en la carpeta del proyecto.
3. Ejecutar: `python main.py`
4. Revisar el archivo `logs/software_fj.log`.
